# AI Travel Planner for Students

An AI-powered travel planning system that helps students generate personalized travel itineraries based on budget, destination, and preferences.

---

## Features
- Personalized travel recommendations
- Budget-friendly itinerary planning
- API integration for travel information
- Destination and route suggestions
- Simple and user-friendly interface

---

## Technologies Used
- Python
- HTML/CSS
- APIs
- Flask
- Machine Learning
